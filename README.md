# Convertir_CodePython____Executable
Je vous montre comment convertir son code python brute en exécutable direct pour Windows


Voici un tutoriel qui vous montre comment créer un exécutable à partir d'un fichier Python en utilisant py2exe ⁴. Voici les étapes à suivre:

1. Tout d'abord, vous devez installer py2exe. Vous pouvez l'installer en utilisant la commande `pip install py2exe` dans votre terminal.
2. Ensuite, vous devez créer un fichier `setup.py` pour votre projet. Ce fichier contiendra les informations nécessaires pour créer l'exécutable.
3. Dans le fichier `setup.py`, vous devez spécifier les fichiers Python que vous souhaitez inclure dans l'exécutable, ainsi que les options de compilation.
4. Enfin, vous pouvez créer l'exécutable en exécutant la commande `python setup.py py2exe` dans votre terminal.

Il est important de noter que py2exe ne prend en charge que les versions de Python incluses dans le cycle de développement officiel ⁸. Si vous utilisez une version plus récente de Python, vous devrez peut-être utiliser une autre méthode pour créer votre exécutable.
